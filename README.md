FinBot – Personal Finance Assistant



Project Overview



FinBot is a personal finance assistant chatbot developed using Python and Jupyter Notebook. It helps users with basic finance-related queries through an interactive chatbot interface.



Features



\* Interactive chatbot interface

\* Responds to finance-related questions

\* Keyword-based response generation

\* User-friendly interface using Python widgets



Technologies Used



\* Python

\* Jupyter Notebook

\* IPyWidgets



Project Structure



\* Finbot\_Personal\_Finance\_Assistant.ipynb – Main project notebook

\* screenshots/ – Screenshots of the chatbot interface



How to Run



1\. Download or clone this repository.

2\. Install the required dependencies:

&#x20;   pip install ipywidgets

3\. Open the notebook in Jupyter Notebook.

4\. Run the notebook cells.
